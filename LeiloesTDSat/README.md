# LeiloesTDSat

## Descrição
Projeto desenvolvido em Java para gerenciamento de uma casa de leilões.

## Tecnologias utilizadas
- Java
- MySQL
- Git
- GitHub

## Banco de dados
O projeto utiliza o banco de dados `uc11`, com a tabela `produtos`.

## Objetivo
Realizar o controle e o gerenciamento dos produtos cadastrados no sistema de leilões.
