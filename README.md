# LeiloesTDSat

## Descrição
Sistema de gerenciamento de produtos de uma casa de leilões.

## Tecnologias utilizadas
- Java
- MySQL
- Git
- GitHub

## Banco de dados
O projeto utiliza o banco de dados uc11 e a tabela produtos.

## Objetivo
Permitir o cadastro e o gerenciamento de produtos utilizados no sistema de leilões.
