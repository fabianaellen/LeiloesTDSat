# Projeto LeiloesTDSat

## Sobre o projeto

O LeiloesTDSat é um sistema desenvolvido em Java para auxiliar nas rotinas de uma casa de leilões, permitindo o gerenciamento de produtos e o acompanhamento de suas informações, como nome, valor e status de venda.

## Tecnologias utilizadas

- Java
- MySQL/MariaDB
- Git
- GitHub
- XAMPP

## Banco de dados

O projeto utiliza o banco de dados `uc11`, que possui a tabela `produtos`, responsável por armazenar as informações dos produtos cadastrados.
